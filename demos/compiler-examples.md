# AMOS Compiler Examples

[Demo gallery](index.md)

19/19 original AMOS programs compile. These development builds include sound, fullscreen, typing controls and debug errors. Compilation does not imply completed execution. Unsupported display geometry and other runtime limits still affect some programs. Supplied graphics, animation files and Galax banks are embedded.
